# 网格资产规范器

## 目的

把尺寸和透明留边不一致的物品图片，规范成 `A × B` 个小格的 Sprite。一个大格固定由 `4 × 4` 个小格组成，A 和 B 都以小格为单位。原始 PNG 不会被修改，Unity 只在导入阶段生成规范后的结果。

## 手动批量处理

1. 在 Unity 的 Project 窗口选择一个或多个图片。
2. 打开 `Tools > 网格资产规范器`。
3. 设置目标宽度 A、高度 B（均为小格数量，支持一位小数），以及每大格的像素、细分数和世界单位。
4. 选择比例处理方式：
   - `ContainWithPadding`：保持比例，空缺部分补透明像素；推荐默认使用。
   - `StretchToFill`：拉伸到完整 A×B，可能造成变形。
   - `CoverAndCrop`：保持比例并填满画布，超出部分会被裁掉。
5. 根据物品的放置逻辑选择 Pivot。
6. 点击“应用到所选素材并重新导入”。

## 自动导入

把图片放在 `Assets/GridItems` 目录或其子目录，文件名以 `_AxB` 结尾：

```text
Crate_4x4.png
LongPlatform_12x4.png
Wall_4x16.png
HalfStep_4.5x2.0.png
```

首次导入默认使用：

- 200 px/大格
- 每个大格细分为 4×4 个小格，因此每小格为 50 px
- 1 Unity 单位/大格，因此每小格为 0.25 Unity Units
- 等比缩放并补透明边
- 自动裁掉原图透明空边
- 中心 Pivot
- Bilinear 采样

如需覆盖默认值，在窗口中选择素材后重新应用配置。

A、B 和每大格世界单位都会规范到小数点后一位。计算出的纹理宽高如果不是整数像素，会四舍五入到最近的整数像素。

## 结果规则

以 `A=12`、`B=8`、`200 px/大格`、`4×4 细分`、`1 Unity 单位/大格` 为例：

- 导入纹理尺寸：`600×400 px`
- `Pixels Per Unit = 200`
- Sprite 世界尺寸：`3×2 Unity Units`

也就是说：`4×4` 是一个大格，`8×4` 是横向两个大格，`12×8` 是 `3×2` 个大格。

之后原图发生变化或执行 Reimport 时，Importer 元数据中的配置仍会自动生效。

## 注意

- 工具会把图片强制作为 `Single Sprite` 导入，不适合直接处理多 Sprite Sheet。
- `StretchToFill` 会改变美术比例；`CoverAndCrop` 会裁掉边缘，使用前应检查预览。
- 如果物品要以格子左下角作为放置原点，Pivot 选择 `BottomLeft`。
- 移除规范配置后重新导入，Unity 会恢复为原始图片内容，但其他由工具设置过的 Sprite 导入参数不会自动还原到使用工具前的自定义值。
